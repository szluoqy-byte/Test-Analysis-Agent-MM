# 示例需求：订单取消 测试设计方案过程报告

## 1. 分析范围

- 需求文档：examples/requirements/sample-requirement.md
- 主交付件：examples/outputs/runs/sample-requirement-run/deliverables/test-design-solution.md

## 2. 方法证据摘要

| 证据ID | 方法 | 需求片段 | 分析结论 | 关联测试点/缺口 |
|---|---|---|---|---|
| ME-001 | 状态转换 | 待支付允许取消、已发货不允许取消 | 需要覆盖允许取消和禁止取消状态 | TP-001、TP-003 |
| ME-002 | 权限分析 | 普通用户只能取消自己的订单 | 需要覆盖本人和非本人订单 | TP-002 |
| ME-003 | 幂等与数据一致性 | 重复取消不能重复释放库存 | 需要覆盖重复取消和库存副作用 | TP-004、TP-006 |
