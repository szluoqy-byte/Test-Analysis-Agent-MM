##### TC-001 普通用户取消本人待支付订单成功闭环

- 前置条件：
  - 1、用户 A 已登录<br/>2、订单 ORDER_1001 属于用户 A<br/>3、订单状态为待支付<br/>4、订单占用库存数量为 1

- 测试数据：
  - user_id=USER_A；说明=订单所有人<br/>order_id=ORDER_1001；说明=待支付订单<br/>cancel_reason=不想购买；说明=取消原因

- 测试步骤：
  - 1、用户 A 打开订单 ORDER_1001 的取消入口<br/>2、用户 A 提交取消原因并确认取消<br/>3、查询订单状态、支付入口、库存占用和取消原因记录

- 预期结果：
  - 1、系统展示可取消入口<br/>2、取消请求被受理<br/>3、订单为取消态，支付入口不可用，库存占用释放，取消原因已记录

- 用例级别：
  - Level 2

- 最终预期：
  - 取消成功，订单不可继续支付，库存释放并记录取消原因。

- 来源引用：
  - 来源=examples/requirements/sample-requirement.md；位置=订单取消；说明=取消后订单不可继续支付，系统释放库存并记录取消原因。
