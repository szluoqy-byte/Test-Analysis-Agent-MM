# 示例需求：订单取消 测试设计方案

## 1. 需求范围

| 字段 | 内容 |
|---|---|
| 需求 ID | 示例需求 |
| 需求名称 | 订单取消 |
| 需求来源 | examples/requirements/sample-requirement.md |
| 设计方案来源 | 未提供 |
| 需求摘要 | 用户在订单未完成前可以取消订单；取消后订单不可继续支付，系统释放库存并记录取消原因。 |
| 设计方案摘要 | 未提供接口路径、请求方式、鉴权方式、错误码、失败原因枚举和幂等实现。 |
| 本次覆盖范围 | 普通用户取消本人订单、非本人订单权限、订单状态限制、重复取消、客服协助取消、库存释放、操作日志、取消接口结果。 |
| 本次不覆盖内容 | 退款、售后、物流拦截、客服审核后台详细流程。 |

## 2. 测试场景与测试设计

### 场景 SC-001：普通用户取消订单

| 字段 | 内容 |
|---|---|
| 场景目标 | 验证普通用户在不同归属和订单状态下的取消规则。 |
| 场景入口/触发方式 | 前端调用订单取消接口。 |
| 执行用户/角色 | 普通用户。 |
| 业务与设计约束 | 普通用户只能取消自己的订单；待支付订单允许取消；已发货订单不允许取消；取消成功后订单不可继续支付。 |

#### 测试点 TP-001：验证待支付本人订单允许取消

| 测试设计项 ID | 测试设计项 | 预期结果 |
|---|---|---|
| TDI-001 | 普通用户取消待支付本人订单 | 取消成功，订单不可继续支付，库存释放并记录取消原因。 |

#### 测试点 TP-002：验证非本人订单取消权限限制

| 测试设计项 ID | 测试设计项 | 预期结果 |
|---|---|---|
| TDI-002 | 普通用户取消非本人订单 | 取消失败。 |

#### 测试点 TP-003：验证已发货订单不允许取消

| 测试设计项 ID | 测试设计项 | 预期结果 |
|---|---|---|
| TDI-003 | 普通用户取消已发货本人订单 | 取消失败。 |

### 场景 SC-002：重复取消与副作用控制

| 字段 | 内容 |
|---|---|
| 场景目标 | 验证重复取消不会造成重复释放库存或重复副作用。 |
| 场景入口/触发方式 | 同一订单重复提交取消请求。 |
| 执行用户/角色 | 普通用户。 |
| 业务与设计约束 | 用户重复提交取消请求时，系统不能重复释放库存。 |

#### 测试点 TP-004：验证重复取消请求的幂等效果

| 测试设计项 ID | 测试设计项 | 预期结果 |
|---|---|---|
| TDI-004 | 本人订单首次取消成功后再次提交取消请求 | 库存不重复释放。 |
| TDI-005 | 同一订单并发提交两次取消请求 | 待人工分析确认 |
