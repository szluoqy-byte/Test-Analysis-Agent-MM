# 测试类型分类速查

本文档只保留本 Agent 生成 `测试用例标题大纲` 时需要的测试类型分类。完整测试理论、行业术语长解释和执行级测试说明不放在本文件中。

## 使用边界

- 用于填写测试场景的 `场景测试类型`。
- 用于填写测试点的 `大类` 和 `子类`。
- 用于质量门禁判断类型是否合理。
- 不用于生成完整测试步骤、完整预期结果或测试执行计划。

## 大类

| 大类 | 定义 | 常见落点 |
|---|---|---|
| 功能性 | 验证业务功能、规则、流程、接口和数据结果是否符合需求 | 主流程、业务规则、接口契约、数据一致性 |
| 可靠性 | 验证失败、超时、重试、恢复、幂等和降级场景下系统是否稳定 | 异常容错、容灾恢复、幂等防护 |
| 性能效率 | 验证响应时间、吞吐、容量、并发和资源使用是否满足约束 | 性能、容量、批量、并发 |
| 兼容性 | 验证版本、平台、渠道、配置、语言地区和开关组合是否符合兼容要求 | 多版本、多端、灰度、feature flag |
| 安全性 | 验证权限、鉴权、敏感数据、越权访问和风控策略是否有效 | 权限、租户隔离、敏感数据保护 |
| 易用性 | 验证用户理解、提示、可操作性、可访问性和交互体验是否可接受 | 表单提示、错误文案、操作反馈 |
| 可维护性 | 验证日志、审计、可观测性、配置和运维诊断能力是否满足维护要求 | 日志、审计、监控、配置变更 |
| 可移植性 | 验证迁移、部署、环境切换和数据导入导出是否具备可移植能力 | 环境迁移、部署适配、数据迁移 |

## 子类

| 子类 | 大类 | 适用信号 | 标题大纲关注 |
|---|---|---|---|
| 功能正确性测试 | 功能性 | 主功能、业务规则、验收标准、页面或接口行为 | 被测对象、条件、验证目标 |
| 功能交互测试 | 功能性 | 多模块联动、端到端链路、跨对象副作用 | 入口、参与方、最终状态和数据变化 |
| 协议一致性测试 | 功能性 | API、消息、回调、字段、错误码、鉴权、幂等 | 请求条件、关键契约、响应和副作用 |
| 数据一致性测试 | 功能性 | 主数据、缓存、搜索、统计、日志、外部系统同步 | 数据对象、同步时机、可观察记录 |
| 边界与等价类测试 | 功能性 | 范围、阈值、金额、数量、长度、格式、枚举 | 有效类、无效类、边界内外 |
| 状态迁移测试 | 功能性 | 生命周期、审批流、订单状态、终态、非法迁移 | 源状态、事件、目标状态、拦截规则 |
| 决策规则测试 | 功能性 | 多条件组合、规则优先级、互斥、默认分支 | 条件组合、结果动作、缺省和冲突 |
| 权限与访问控制测试 | 安全性 | 角色、租户、归属、资源、动作、数据范围 | 授权关系、拒绝关系、越权风险 |
| 安全风控测试 | 安全性 | 敏感操作、隐私数据、风控策略、频控、审计 | 风险触发条件、拦截和留痕 |
| 容错容灾测试 | 可靠性 | 失败、超时、重试、回滚、补偿、降级 | 异常触发、恢复状态、一致性 |
| 幂等与重复提交测试 | 可靠性 | 重复请求、重复点击、重复回调、并发提交 | 去重依据、副作用次数、最终状态 |
| 性能测试 | 性能效率 | 响应时间、吞吐、并发、耗时、资源 | 指标、负载条件、判定口径 |
| 容量测试 | 性能效率 | 批量上限、列表容量、文件大小、配额、队列堆积 | 容量边界、处理结果、告警或降级 |
| 兼容性测试 | 兼容性 | 版本、平台、渠道、语言地区、开关、配置组合 | 关键组合、差异行为、不兼容关系 |
| 配置与灰度测试 | 兼容性 | feature flag、灰度策略、配置变更、回滚 | 开关状态、生效范围、回滚行为 |
| 易用性测试 | 易用性 | 文案、提示、错误反馈、可理解性、可访问性 | 用户可理解信息和操作反馈 |
| 日志审计测试 | 可维护性 | 操作日志、审计记录、监控、告警、追踪 ID | 记录内容、关联对象、可追踪性 |
| 迁移与部署适配测试 | 可移植性 | 数据迁移、环境切换、部署差异、导入导出 | 迁移前后数据、环境依赖和兼容结果 |

## 场景测试类型选择

| 场景信号 | 推荐场景测试类型 |
|---|---|
| 单一业务功能或规则验证 | 功能正确性测试 |
| 跨模块、跨系统或端到端流程 | 功能交互测试 |
| 接口、消息、回调或第三方集成 | 协议一致性测试 |
| 状态、生命周期、审批、取消、超时 | 状态迁移测试 |
| 多条件规则、开关、优先级或互斥关系 | 决策规则测试 |
| 缓存、搜索、统计、日志或多对象副作用 | 数据一致性测试 |
| 角色、租户、归属、审批权限或数据范围 | 权限与访问控制测试 |
| 超时、失败、重试、补偿、降级 | 容错容灾测试 |
| 重复请求、重复回调、并发提交 | 幂等与重复提交测试 |
| 版本、平台、渠道、配置组合 | 兼容性测试 |
| 响应时间、吞吐、容量、并发 | 性能测试或容量测试 |
| 日志、审计、监控、告警 | 日志审计测试 |

## 使用规则

- 主输出中优先使用上表子类，避免自造类型。
- 一个测试点只选择一个最主要的大类和子类；其他关注点写入风险或判定关注。
- 如果需求只有弱信号，不强行扩大为性能、安全或兼容专项；可写入待确认信息。
- 类型用于表达覆盖视角，不替代测试技术。测试技术仍以 `knowledge/test-techniques/README.md` 和 `knowledge/test-method-routing-matrix.md` 为准。
