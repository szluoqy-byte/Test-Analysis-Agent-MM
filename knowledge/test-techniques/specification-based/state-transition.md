# 状态转换测试技术 STT

## 方法定义

状态转换测试技术用于验证对象在事件触发下从一个状态迁移到另一个状态的行为。它关注状态集合、事件、动作、合法迁移、非法迁移和状态保持。

STT 适合审批、订单、任务、账户、工单等具有生命周期的对象。

## 适用场景

- 对象存在明确状态：待提交、待审批、已通过、已拒绝、已取消。
- 操作是否允许取决于当前状态。
- 事件会触发状态变化、回退、超时或终止。
- 存在非法迁移或不可逆状态。
- 页面按钮、接口动作随状态变化。

## 不适用场景

- 只有单个校验点，应使用 DPT。
- 重点是账期、批次或时间周期，应使用 PCT。
- 多条件共同决定动作但不涉及状态机，应使用 DTT。

## 建模输入

| 元素 | 说明 |
|---|---|
| 状态集合 | 对象可能处于的状态 |
| 初始状态 | 测试设计项覆盖前对象状态 |
| 事件/操作 | 触发状态变化的动作 |
| 目标状态 | 事件成功后的状态 |
| 非法迁移 | 不允许发生的状态变化 |
| 副作用 | 通知、日志、数据锁定、按钮变化 |

## 设计步骤

1. 列出状态集合和初始状态。
2. 画出合法迁移：当前状态 + 事件 -> 目标状态。
3. 标记非法迁移和不可逆迁移。
4. 设计主状态链路测试设计项。
5. 设计关键非法迁移拦截测试设计项。
6. 设计超时、回退、撤回、取消、重试等特殊迁移。
7. 验证状态变化后的可操作入口、按钮、接口和数据记录。

## 测试设计项派生规则

| 迁移类型 | 派生方式 |
|---|---|
| 合法迁移 | 从源状态触发事件，验证目标状态 |
| 非法迁移 | 从不允许的源状态触发事件，验证拦截和状态保持 |
| 状态保持 | 操作失败或条件不满足时状态不变 |
| 回退/撤回 | 验证状态回到指定状态 |
| 超时迁移 | 验证定时或超时事件触发状态变化 |
| 不可逆迁移 | 验证终态不允许再次操作 |

## 数量控制

- `Level 0/1` 覆盖主状态链路和关键非法迁移。
- 状态很多时，优先覆盖高风险状态和终态。
- 相同类型的非法迁移可选择代表状态。
- 状态按钮或权限差异明显时，需要补充专项测试设计项。

## 输入条件与数据依赖关注

- 准备处于指定初始状态的业务对象。
- 明确触发事件所需角色和权限。
- 对超时迁移准备系统时间或任务触发条件。

## 测试设计项生成关注

- 先确认对象处于源状态。
- 触发一个明确事件。
- 操作后观察状态、入口、按钮和记录。

## 预期结果依据

- 目标状态正确。
- 非法迁移被拦截，源状态保持。
- 状态变化产生必要通知、日志或审计。
- 状态变化后可用操作集合正确。
- 终态不可逆时不允许再次修改。

## 常见误区

- 只测主链路，不测非法迁移。
- 只看状态字段，不看按钮、权限和副作用。
- 把周期边界当成状态迁移处理。
- 未准备明确初始状态，导致测试设计项无法落地。

## 测试设计项示例

### 示例：订单支付状态迁移

**测试场景**：用户对订单执行支付、取消和重复通知处理。

**规格摘要**：

- `待支付` 订单支付成功后进入 `已支付`。
- `待支付` 订单用户取消后进入 `已取消`，并释放占用资源。
- `已取消` 订单不允许再次支付，返回 `ORDER_STATUS_NOT_PAYABLE`。
- `已支付` 订单不允许再次取消，返回 `ORDER_STATUS_NOT_CANCELABLE`。
- 非法迁移必须保持原状态，并记录失败原因。

**测试点**：验证订单支付状态的合法迁移、非法迁移和终态保护。

| 测试设计项 ID | 测试设计项 | 预期结果 |
|---|---|---|
| TDI-001 | 待支付订单收到支付成功事件 | 订单状态变为已支付，并生成一条支付成功记录 |
| TDI-002 | 待支付订单由用户发起取消 | 订单状态变为已取消，占用资源按取消规则释放 |
| TDI-003 | 已取消订单再次发起支付 | 返回 `ORDER_STATUS_NOT_PAYABLE`，订单状态保持已取消，不生成支付成功记录 |
| TDI-004 | 已支付订单再次发起用户取消 | 返回 `ORDER_STATUS_NOT_CANCELABLE`，订单状态保持已支付 |
| TDI-005 | 已支付订单重复收到同一笔支付成功通知 | 订单状态保持已支付，不重复生成支付成功记录 |

**设计要点**：

- 合法迁移和非法迁移必须拆开，不把“状态流转正常”写成一条泛化设计项。
- 终态保护要覆盖“再次操作”和“重复事件”两类触发方式。
- 如果需求没有说明错误码、失败原因或副作用，相关预期结果写 `待人工分析确认`。
