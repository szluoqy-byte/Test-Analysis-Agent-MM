# 方法分析证据模板

```markdown
## 方法分析证据摘要

| 证据ID | 方法 | 需求片段 | 分析结论 | 关联测试点/待确认 |
|---|---|---|---|---|
| ME-001 | 状态迁移 |  |  | TP-001 / Q-001 |
```

## 字段规则

- `证据ID`：`ME-001` 格式，按顺序递增。
- `方法`：来自 `knowledge/testpoint-standard.md` 的标准方法。
- `需求片段`：被该方法分析的需求摘要。
- `分析结论`：该方法识别出的状态、规则、边界、权限、接口、数据或风险结论；必要时点明对应分析维度。
- `关联测试点/待确认`：关联 `TP-*` 或 `Q-*`，不能为空。

## 使用规则

- 每个路由表中标记为 `必选` 的方法，都应有方法证据或待确认问题解释。
- 方法证据只展示专家分析过程，不替代测试设计方案。
- 测试设计方案文件不包含方法证据。
